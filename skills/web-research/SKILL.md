# Web Research & Content Extraction Skill

## Capabilities
- Search the web for recent events, technical solutions, and references (`web_search` tool).
- Fetch clean, readable text from arbitrary HTTP/HTTPS URLs (`web_fetch` tool).
- Search YouTube video titles and metadata (`youtube` tool).

## Workflow Guidelines
1. Execute `web_search` to find relevant sources and URLs.
2. If in-depth text is required from a source, call `web_fetch` with the source URL.
3. Synthesize findings concisely with references, never guessing unverified information.
